# Identidad visual de FÚTBOL CHILENSIS

## Archivos maestros

- `youtube-banner.svg`: 2560 × 1440 px. Nombre y línea editorial dentro del área segura central de 1546 × 423 px.
- `profile-chilensis.svg`: avatar 800 × 800 px, preparado para recorte circular.
- `chilensis-futbol-logo.svg`: logotipo horizontal.

## Exportación para YouTube

YouTube no acepta SVG como archivo de banner o avatar. Exporta los SVG maestros a PNG o JPEG sin cambiar sus dimensiones. Revisa el recorte en TV, escritorio y móvil antes de aplicar el banner en YouTube Studio.

## Miniaturas generadas por el pipeline

- Shorts: 1080 × 1920 px, una por cada render.
- Videos largos: 1280 × 720 px, una por cada render.
- Los escudos solo se muestran si existe una imagen HTTPS autorizada en `TEAM_IMAGES_JSON` y vinculada al equipo correcto. Si no, la plantilla usa iniciales y tipografía.
