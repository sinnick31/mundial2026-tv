# Manual de operaciones de la sala de prensa

Este índice conecta las guías del sistema editorial y de crecimiento de MUNDIAL2026SHORTS.

## Orden recomendado

1. [Sistema operativo de prensa](SISTEMA_OPERATIVO_PRENSA.md): posicionamiento, calendario, formatos, flujo y estándares.
2. [Protocolo editorial y derechos](PROTOCOLO_EDITORIAL_Y_DERECHOS.md): verificación, semáforo editorial y audiovisual.
3. [Plan de 30 días](PLAN_DE_30_DIAS.md): ejecución práctica y experimentos de crecimiento.
4. [Métricas y aprendizaje](METRICAS_Y_APRENDIZAJE.md): lectura de Studio y ciclo de pruebas.
5. [Monetización y modelo de negocio](MONETIZACION_Y_MODELO_DE_NEGOCIO.md): rutas de ingresos y requisitos a comprobar.
6. [Ficha editorial de noticia](../templates/brief-editorial.md): completar antes de aprobar una historia.
7. [Registro de métricas](../templates/seguimiento-publicaciones.csv): medir a 24 horas y 7 días.
8. [Formulario de propuesta editorial](../.github/ISSUE_TEMPLATE/propuesta-editorial.yml): usar Issues para proponer nuevas historias.

## Principio de seguridad

Este conjunto de documentos no modifica por sí solo el pipeline de publicación ni las credenciales. Los cambios de código o workflows deben revisarse y probarse por separado. Nunca se publican historias solo para cumplir una cuota.
