# Copias de origen de las skills

La ubicación activa y compatible con la detección automática de OpenAI Codex es `.agents/skills/`. Consulta:

- `AGENTS.md` para las reglas permanentes de activación y uso.
- `.agents/skills/README.md` para el catálogo, comandos y pruebas.

Esta carpeta conserva la copia original importada desde el proyecto upstream como referencia histórica. Para ejecutar herramientas desde la raíz del repositorio, utiliza las rutas de `.agents/skills/`.
